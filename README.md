# LIW — LOST IN WIRED

Сайт-портфолио независимого веб-разработчика. Задача сайта — приводить клиентов, которым нужна разработка сайта: посетитель за несколько секунд понимает, что вы делаете сайты на заказ, что они работают на телефоне и компьютере, и может либо написать в WhatsApp, либо оставить заявку (она придёт вам в Telegram).

**Технологии:** обычные HTML, CSS и JavaScript (без React и других фреймворков) + одна серверная функция Netlify для отправки заявок в Telegram. Никаких зависимостей устанавливать не нужно.

**Главное правило:** весь контент сайта — номера, тексты, услуги, работы, отзывы, FAQ, цвета — меняется **в одном файле: `config.js`**. В HTML искать ничего не нужно.

## 0. Что внутри проекта

```
/
├── index.html              ← каркас страницы (контент сюда не пишем)
├── config.js               ← ВСЕ тексты, контакты, услуги, работы, отзывы, FAQ, цвета
├── 404.html                ← страница «не найдено»
├── favicon.svg             ← логотип LIW (SVG, легко редактировать)
├── apple-touch-icon.png    ← иконка для iPhone (180×180)
├── og-image.png            ← картинка для превью ссылки в мессенджерах (1200×630)
├── robots.txt              ← инструкции для поисковиков
├── sitemap.xml             ← карта сайта
├── netlify.toml            ← настройки Netlify (сборка, заголовки безопасности, CSP)
├── package.json            ← только команды-ярлыки, зависимостей нет
├── css/
│   └── style.css           ← весь дизайн
├── js/
│   └── app.js              ← рисует страницу из config.js, меню, форма, анимации
├── images/
│   └── projects/           ← сюда кладите картинки проектов
├── netlify/
│   └── functions/
│       └── lead.js         ← серверная функция: принимает заявку → Telegram
└── scripts/
    ├── build.cjs           ← сборка в папку dist/ (запускает Netlify сам)
    └── test-lead.cjs       ← автотест серверной функции
```

**Как это работает.** Браузер загружает `index.html`, затем `config.js` и `app.js`. Скрипт `app.js` читает `CONFIG` и строит страницу. Если в `config.js` какое-то значение пустое (`""` или `[]`) — соответствующий блок, кнопка или пункт меню **автоматически исчезает**.

**Что делает сборка (`scripts/build.cjs`).** Netlify запускает её при каждом деплое. Она копирует в папку `dist/` только публичные файлы (README, тесты и служебное не публикуются) и подставляет в `index.html`, `robots.txt` и `sitemap.xml` адрес сайта, `title` и `description` из `config.js`.

**Шрифты.** Используется системный шрифтовой стек (Inter → Segoe UI → SF Pro → системный). Это быстро, не требует внешних загрузок и не нарушает Content-Security-Policy. Если захотите свой шрифт — положите файлы `.woff2` в папку `fonts/`, добавьте `@font-face` в начало `css/style.css` и поменяйте переменную `--font`.

## 1. Как запустить сайт локально

Нужен только Python 3 (на macOS и Linux он обычно уже есть; на Windows — установите с python.org).

1. Откройте терминал (на Windows — PowerShell).
2. Перейдите в папку проекта:
   ```bash
   cd путь/к/liw-site
   ```
3. Запустите локальный сервер:
   ```bash
   python3 -m http.server 8000
   ```
   (на Windows может понадобиться `python -m http.server 8000`)
4. Откройте в браузере: **http://localhost:8000**
5. Остановить сервер: `Ctrl + C` в терминале.

После правок в `config.js` или CSS достаточно обновить страницу (`Ctrl/Cmd + Shift + R`, чтобы сбросить кэш).

> **Важно.** Так сайт открывается целиком, **но форма заявки локально не отправится** — серверная функция работает только на Netlify. Кнопка покажет вежливое сообщение об ошибке — это нормально. Чтобы проверить форму на своём компьютере, используйте Netlify CLI:
> ```bash
> npm install -g netlify-cli
> netlify dev
> ```
> Для `netlify dev` создайте файл `.env` в корне проекта (он уже в `.gitignore`, в GitHub не попадёт):
> ```
> TG_TOKEN=ваш_токен
> TG_CHAT_ID=ваш_chat_id
> ```
> После этого сайт откроется на http://localhost:8888 и заявки будут уходить в Telegram по-настоящему.

Проверить серверную функцию без Telegram (нужен Node.js 18+):
```bash
node scripts/test-lead.cjs
```

## 2. Что заменить в первую очередь

В проекте стоят безопасные примерные значения. **Перед запуском замените их в `config.js`:**

| Что | Где в `config.js` | Сейчас |
|---|---|---|
| Телефон (для ссылки `tel:`) | `contact.phone` | `+71234567890` |
| Телефон (как виден на сайте) | `contact.phoneDisplay` | `+7 123 456 78 90` |
| Номер WhatsApp (только цифры) | `contact.whatsapp` | `71234567890` |
| Telegram (необязательно) | `contact.telegram` | пусто |
| Email (необязательно) | `contact.email` | пусто |
| Адрес сайта | `seo.siteUrl` | пусто (подставится адрес Netlify) |

А также:

- в Netlify задать переменные `TG_TOKEN` и `TG_CHAT_ID` (разделы 9–12) — **без них форма не будет доставлять заявки**;
- при желании заменить `og-image.png` (картинка-превью ссылки, 1200×630) и `favicon.svg`.

## 3. Как изменить тексты, контакты, услуги, FAQ

Откройте `config.js` в любом текстовом редакторе (VS Code, Блокнот, Sublime). Файл поделён на нумерованные разделы с комментариями. **Меняйте только то, что внутри кавычек `" "`.** Кавычки, запятые и скобки удалять нельзя.

### Название бренда (LIW и LOST IN WIRED)
```js
brand: {
  name: "LIW",               // крупное название
  fullName: "LOST IN WIRED"  // маленькая подпись
},
```

### Телефон, WhatsApp, Telegram, email
```js
contact: {
  phone: "+71234567890",             // для tel: — с плюсом, без пробелов
  phoneDisplay: "+7 123 456 78 90",  // как показывается посетителю
  whatsapp: "71234567890",           // только цифры, без «+» и пробелов
  whatsappMessage: "Здравствуйте! Хочу обсудить разработку сайта.",
  telegram: "",                      // например "my_nick" (без @)
  email: ""                          // например "hello@example.com"
},
```
- **Телефон и WhatsApp — разные настройки.** Если у вас один номер — впишите его в оба поля. Если номера разные — впишите каждый в своё поле: сайт работает корректно в обоих случаях.
- Пустое значение = соответствующая кнопка/строка не показывается. Если пусты и телефон, и WhatsApp, и Telegram, и email — раздел «Контакты» и пункт меню скрываются сами.
- Текст, который появится в WhatsApp при нажатии кнопки, меняется в `whatsappMessage`.

### Социальные сети
```js
socialLinks: [
  { label: "Instagram", url: "https://instagram.com/ваш_ник" },
  { label: "GitHub",    url: "https://github.com/ваш_ник" }
],
```
Ссылки принимаются только вида `http://` и `https://`. Пустой массив `[]` — блока нет.

### Главный экран, тексты, кнопки
Раздел `hero`: заголовок (`title`), выделяемая цветом часть заголовка (`titleAccent` — должна дословно встречаться в `title`; оставьте `""`, если выделять не нужно), описание (`text`), кнопки, приписка про цену (`priceNote`), пять коротких пунктов (`points`).

### Услуги
```js
services: {
  title: "Какой сайт вам нужен",
  items: [
    { icon: "card", title: "Сайт-визитка", description: "Компактный сайт для ..." },
    // ...
  ]
}
```
Чтобы **добавить** услугу — скопируйте одну строку `{ ... },` и поменяйте текст. Чтобы **удалить** — удалите всю строку `{ ... },`. Доступные иконки: `card`, `page`, `building`, `sliders`.

### Что можно подключить
Раздел `features.items` — простой список строк в кавычках через запятую.

### Как проходит работа
Раздел `process.steps` — список шагов; нумерация (01, 02, …) проставляется сама.

### FAQ (частые вопросы)
```js
faq: {
  items: [
    { question: "Сколько стоит разработка сайта?", answer: "Стоимость зависит от ..." },
    // ...
  ]
}
```
Добавлять и удалять вопросы — так же, как услуги.

### Меню
Раздел `nav`. Пункты, для которых на странице нет раздела (например «Работы», пока нет проектов), скрываются сами.

### Название и описание сайта для поисковиков
```js
seo: {
  title: "LIW — разработка сайтов для бизнеса",
  description: "Создание современных сайтов под задачи бизнеса. ...",
  siteUrl: ""   // например "https://liw.kz" — без слэша в конце
}
```
`siteUrl` используется в canonical, Open Graph, `robots.txt` и `sitemap.xml`. Если оставить пустым — при деплое на Netlify подставится адрес сайта Netlify автоматически. **Когда подключите свой домен — впишите его сюда.**

### Другие тексты
`form` (подписи полей, сообщения успеха и ошибок), `contactsSection`, `texts`.

## 4. Как добавить проект в портфолио

Пока в `config.js` написано `projects: [],` — раздел «Работы» **полностью скрыт** (и пункт меню тоже, и кнопка «Посмотреть работы» в первом экране заменяется на «Что я делаю»). Никаких надписей вроде «Пока работ нет» нет.

Как только вы добавите хотя бы один проект — раздел появится автоматически.

Найдите в `config.js`:
```js
projects: [],
```
и замените на:
```js
projects: [
  {
    title: "Название проекта",
    category: "Сайт для бизнеса",
    description: "Краткое описание проекта",
    image: "/images/projects/project-1.webp",
    url: "https://example.com",
    tags: ["Адаптивный дизайн", "WhatsApp"]
  }
],
```

Для второго проекта поставьте запятую после `}` и добавьте ещё один блок `{ ... }`:
```js
projects: [
  { title: "Проект 1", category: "...", description: "...", image: "...", url: "...", tags: [] },
  { title: "Проект 2", category: "...", description: "...", image: "...", url: "...", tags: [] }
],
```

| Поле | Что это | Обязательно |
|---|---|---|
| `title` | название | да |
| `category` | подпись над названием («Лендинг», «Сайт для бизнеса») | нет |
| `description` | короткое описание | нет |
| `image` | путь к картинке (см. раздел 5) | нет — тогда показывается красивая заглушка с первой буквой |
| `url` | куда ведёт карточка (открывается в новой вкладке) | нет — тогда карточка без ссылки |
| `tags` | список тегов-«таблеток» | нет |

> Допустимы только ссылки `http://` и `https://`. Всё остальное (например `javascript:`) сайт игнорирует — это защита.

## 5. Как добавить изображение проекта

1. Сделайте скриншот сайта-проекта. Рекомендуем пропорции **16:10** (например, 1200×750 px), формат **WebP** или JPG, вес до 200–300 КБ.
2. Назовите файл латиницей, без пробелов: `project-1.webp`.
3. Положите его в папку `images/projects/`.
4. В `config.js` у проекта укажите:
   ```js
   image: "/images/projects/project-1.webp",
   ```
5. Обновите страницу.

Если файл не найден или путь указан неверно, сайт не покажет «битую» картинку — вместо неё будет аккуратная заглушка.

## 6. Как добавить настоящий отзыв

> ⚠️ Добавляйте **только реальные отзывы реальных клиентов с их согласия**. Выдуманные отзывы и неподтверждённые цифры («100+ довольных клиентов») на сайт добавлять нельзя — это обман клиентов и репутационный риск.

Пока написано `reviews: [],` — раздел «Отзывы» полностью скрыт. Замените на:
```js
reviews: [
  {
    name: "Имя клиента",
    company: "Название бизнеса",
    text: "Текст настоящего отзыва",
    project: "Сайт для бизнеса"
  }
],
```
Для нескольких отзывов — несколько блоков `{ ... }` через запятую. Поля `name`, `company`, `project` необязательны; `text` — обязателен.

Раздел и пункт меню появятся автоматически.

## 7. Как удалить отзыв

Удалите нужный блок `{ ... },` целиком. Если удалите все — оставьте `reviews: [],` и раздел снова скроется сам.

> **На первой версии посетители не могут публиковать отзывы сами** — только вы добавляете их вручную. В коде это подготовлено к будущему расширению (см. раздел 21).

## 8. Как изменить цвета

В `config.js`, раздел `theme`:
```js
theme: {
  bg: "#09090b",          // фон страницы
  surface: "#131316",     // карточки
  text: "#f3f3f1",        // основной текст
  muted: "#9a9aa2",       // второстепенный текст
  accent: "#ff6b3d",      // акцент (кнопки, выделения)
  accentInk: "#140803"    // цвет текста на акцентных кнопках
}
```
Любой CSS-цвет: `#ff6b3d`, `rgb(255,107,61)`, `hsl(14 100% 62%)`. Остальные оттенки (границы, подсветки, свечение) рассчитываются автоматически.

Идеи для акцента: `#7c8cff` (холодный фиолетово-синий), `#e5c07b` (тёплый золотой), `#5ad0c8` (мятный). Если меняете `accent` на светлый цвет — `accentInk` оставьте тёмным, на тёмный — сделайте светлым.

Цвет логотипа меняется отдельно: откройте `favicon.svg` в текстовом редакторе — цвета записаны там как `#f3f3f1` (буквы) и `#ff6b3d` (точка).

## 9. Telegram-бот: создание через BotFather

Заявки с сайта приходят вам в личные сообщения Telegram от вашего собственного бота.

1. Откройте Telegram и найдите **@BotFather** (официальный бот с галочкой).
2. Отправьте команду `/newbot`.
3. BotFather спросит **название** бота (отображаемое имя, любое) — например, `LIW Заявки`.
4. Затем спросит **username** — латиницей, должно заканчиваться на `bot`, например `liw_leads_bot`. Если занято — попробуйте другое.
5. BotFather пришлёт сообщение с токеном — это и есть `TG_TOKEN` (раздел 10).
6. **Обязательно** откройте своего бота (ссылка `t.me/ваш_username` из сообщения BotFather) и нажмите **Start** / отправьте любое сообщение. Пока вы сами не написали боту, он не сможет писать вам.

## 10. Как получить TG_TOKEN

Токен — это строка из BotFather, похожая на:
```
цифры:длинная_строка_из_букв_цифр_и_подчёркиваний
```
Если потеряли: в @BotFather отправьте `/mybots` → выберите бота → **API Token**.

> 🔒 **Токен — это пароль от вашего бота.** Кто его знает — может писать от имени бота. Никому не отправляйте, не вставляйте в код, `config.js`, README, GitHub, скриншоты и переписки. Если токен случайно «засветился» — сразу в @BotFather: `/revoke` → выберите бота → получите новый токен и обновите его в Netlify.

## 11. Как получить TG_CHAT_ID

`TG_CHAT_ID` — числовой идентификатор вашего чата с ботом (куда присылать заявки).

**Способ 1 — через getUpdates (без сторонних ботов):**
1. Убедитесь, что вы нажали **Start** у своего бота (шаг 6 раздела 9) и отправили ему любое сообщение.
2. Откройте в браузере (подставьте свой токен):
   ```
   https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
   ```
3. Найдите в ответе фрагмент `"chat":{"id":123456789,...}` — число после `"id":` и есть ваш `TG_CHAT_ID`.
4. Если ответ пустой (`"result":[]`) — напишите боту ещё одно сообщение и обновите страницу.

> Не публикуйте и не пересылайте эту ссылку с токеном — она содержит ваш секрет.

**Способ 2 — через бота-помощника:** напишите в Telegram боту **@userinfobot** — он ответит вашим `Id`. Это число и есть `TG_CHAT_ID` для личных сообщений.

**Если заявки должны приходить в группу:** добавьте бота в группу, напишите там любое сообщение и откройте `getUpdates`. У групп `id` — отрицательное число (например `-1001234567890`); вписывайте его вместе с минусом.

## 12. Как добавить TG_TOKEN и TG_CHAT_ID в Netlify

Секреты хранятся **только** в настройках Netlify — не в коде и не в GitHub.

1. Зайдите на [app.netlify.com](https://app.netlify.com) → откройте ваш сайт.
2. **Site configuration** → **Environment variables**.
3. Нажмите **Add a variable** (или **Add a single variable**).

## 16. Как подключить собственный домен

1. Купите домен у любого регистратора (например, Namecheap, Cloudflare, reg.ru, hoster.kz, nic.kz — зависит от зоны).
2. В Netlify: **Domain management** → **Add a domain** → введите домен (`example.com`) → подтвердите.
3. Netlify покажет, какие **DNS-записи** нужно создать. Есть два пути:
   - **Использовать DNS Netlify** (рекомендуется): Netlify даст адреса серверов имён (NS) — впишите их в панели регистратора.
   - **Оставить DNS у регистратора:** создайте у него записи, которые покажет Netlify (обычно `A`-запись для `example.com` и `CNAME` для `www` на ваш `*.netlify.app`). Берите значения **только из подсказок Netlify**: они могут меняться.
4. Подождите: изменения DNS применяются от нескольких минут до 24–48 часов.
5. **HTTPS** (SSL-сертификат) Netlify выпускает автоматически: **Domain management** → **HTTPS** → **Verify DNS configuration** → **Provision certificate**, если не выпустился сам.
6. Когда домен заработает — впишите его в `config.js`:
   ```js
   seo: { ..., siteUrl: "https://example.com" }
   ```
   и сделайте деплой — это обновит canonical, `sitemap.xml`, `robots.txt` и картинку для превью.
7. Выберите основной домен (с `www` или без) и включите перенаправление второго на основной в **Domain management**.
8. (По желанию) добавьте сайт в [Google Search Console](https://search.google.com/search-console) и отправьте `https://example.com/sitemap.xml`.

## 20. Безопасность: как устроена защита

**Заявка:** форма отправляет JSON на `/.netlify/functions/lead`. Функция `netlify/functions/lead.js`:

- принимает только `POST` с `Content-Type: application/json`;
- ограничивает размер запроса и длину каждого поля (телефон — 30, имя — 80, бизнес — 120, описание — 1500 символов);
- проверяет телефон на сервере (допустимые символы, 10–15 цифр);
- очищает ввод: убирает управляющие и невидимые символы, схлопывает пробелы;
- экранирует HTML перед отправкой в Telegram — вставить ссылки или теги через форму нельзя;
- **honeypot:** скрытое поле `website`; если бот его заполнил, функция отвечает «успех», но ничего не отправляет;
- **rate limit:** не более 5 заявок за 10 минут с одного IP (ответ `429`);
- принимает запросы только с того же сайта (проверка `Origin`);
- при сбое возвращает общий ответ без технических подробностей; токен и пользовательские данные в логи не пишутся.

> **Про rate limit:** счётчик хранится в памяти функции. Это простая защита от обычного спама. Для серьёзных атак добавьте защиту перед сайтом (Cloudflare, Netlify Rate Limiting на платных тарифах, капча).

**Заголовки** (`netlify.toml`): `Content-Security-Policy` (запрещает inline-скрипты и сторонние скрипты), `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy`, `Permissions-Policy`, `Strict-Transport-Security`.

> **CSP и внешние ресурсы.** В политике разрешены только свои скрипты, стили и шрифты (`'self'`), а картинки — свои и по `https:`. Если позже подключите аналитику, карту, виджет чата или Google Fonts — добавьте их домены в `Content-Security-Policy` в `netlify.toml`, иначе браузер их заблокирует.

**Фронтенд:** данные из `config.js` и из формы никогда не вставляются через `innerHTML` — только как текст. Ссылки из `config.js` проходят проверку: допускаются лишь `http://` и `https://`.

## 22. Частые проблемы

**Заявка не приходит в Telegram.**
1. Проверьте, что переменные называются точно `TG_TOKEN` и `TG_CHAT_ID`, а значения без пробелов и кавычек.
2. После добавления переменных сделайте **новый деплой** (раздел 12).
3. Убедитесь, что вы нажали **Start** у своего бота.
4. Проверьте `chat_id` через `getUpdates` (раздел 11).
5. Посмотрите логи: Netlify → **Logs** → **Functions** → `lead`.

**Форма пишет «Не удалось отправить заявку».**
Локально через `python3 -m http.server` это ожидаемо — функции там нет (используйте `netlify dev`). На Netlify — смотрите пункт выше.

**Пишет «Слишком много заявок».** Сработал rate limit (5 заявок за 10 минут с одного IP). Подождите или тестируйте с другого соединения.

**Сайт пустой/пропали секции.** Скорее всего, ошибка в `config.js` (потеряна запятая, кавычка или скобка). Откройте консоль (F12 → Console) — там будет строка с ошибкой. Проверьте файл командой `node -e "require('vm').runInNewContext(require('fs').readFileSync('config.js','utf8')+';CONFIG')"` — если ошибок нет, синтаксис в порядке.

**Картинка проекта не отображается.** Проверьте путь (начинается с `/images/projects/`), регистр букв и расширение файла (`.webp` ≠ `.WEBP` на сервере).

**Изменения в `config.js` не видны.** Обновите страницу с очисткой кэша (`Ctrl/Cmd + Shift + R`). На Netlify — убедитесь, что изменения закоммичены и задеплоены.

**В `canonical` или `sitemap.xml` вижу `__SITE_URL__` или `localhost`.** Вы смотрите исходный файл, а не результат сборки. На Netlify подстановка делается автоматически. Локально можно выполнить `node scripts/build.cjs` и открыть папку `dist/`.
