Политика конфиденциальности

Эта политика объясняет, какие данные могут быть получены через сайт LIW и для чего они используются.

1. Какие данные собираются

При отправке формы пользователь указывает номер телефона или WhatsApp. По желанию также можно указать имя, название бизнеса, тип проекта и описание задачи.

2. Для чего используются данные

Данные используются только для обработки заявки, связи с пользователем и обсуждения разработки сайта или связанных с ней услуг.

3. Как передаются и обрабатываются данные

Заявка обрабатывается средствами сайта и может передаваться администратору LIW через Telegram для получения уведомления и последующей связи. Для размещения и технической работы сайта используется инфраструктура Netlify.

4. Передача третьим лицам

Данные не предназначены для продажи или рекламной рассылки третьих лиц. Технические сервисы, необходимые для работы сайта и доставки заявки, могут обрабатывать данные в объёме, необходимом для предоставления своих услуг.

5. Срок хранения

Данные хранятся только столько, сколько это необходимо для обработки обращения, дальнейшего общения по проекту и выполнения связанных с ним договорённостей, если более длительное хранение не требуется по закону.

6. Согласие и обращение пользователя

Отправляя форму после установки отметки согласия, пользователь подтверждает согласие на обработку указанных им данных для описанных выше целей. По вопросам, связанным с данными, пользователь может обратиться к LIW через доступные на основном сайте способы связи.

7. Изменения политики

Политика может обновляться при изменении работы сайта, используемых сервисов или требований законодательства. Актуальная версия публикуется на этой странице.
